# RollUp.az — Peşəkar Roll-Up Banner və Portativ Sərgi Sistemləri

Azərbaycanın etibarlı portativ reklam və sərgi stendləri istehsalçısı **RollUp.az** üçün müasir, yüksək sürətli və satış yönümlü veb sayt platforması.

## 🌟 Əsas Xüsusiyyətlər

- **Yüksək Kontrastlı Dark Obsidian Dizayn:** Neon Aqua Cyan (`#00e5ff`), Flame Orange (`#ff6b00`) və dərin obsidian arxa plan ilə ultra-modern vizual üslub.
- **Satış və Dönüşüm Yönümlü:** Dərhal WhatsApp sifariş inteqrasiyası, zəmanət və ekspress çatdırılma indikatorları.
- **Roll-Up Standın Quruluşu və Mexanizmi:** Alüminium kaset, teleskopik dirək, üst klips və yay sistemini addım-addım izah edən interaktiv təhsil bölməsi.
- **Şəffaf Model Müqayisəsi:** Roll-Up Silver, Roll-Up Premium və X-Banner modellərinin texniki fərqlərini göstərən müqayisə bələdçisi.
- **Çoxbucaq Qalereyalı Məhsul Modalı:** Hər məhsul üçün daşıma çantası, mexanizm detalları, ölçü seçicisi və anlıq WhatsApp sifarişi.
- **İnteraktiv Sifariş Terminalı:** Stand növü, çap dizaynı vəziyyəti və təcililik seçimləri ilə sürətli konfiqurasiya kiosk modulu.
- **Həcm Endirimi Kalkulyatoru:** Material dərəcələri, əlavə xidmətlər və 5-10% avtomatik həcm endirimi.
- **Tam 3 Dilli Sistem (AZ / RU / EN):** Bütün məzmun 3 dildə dəqiq tərcümə ilə təchiz edilib.
- **100% Mobil Uyğunluq (Responsive):** Telefonda sağa-sola sürüşmənin (horizontal wobble) qarşısı tam alınıb, şaquli sabit sürüşmə təmin edilib.
